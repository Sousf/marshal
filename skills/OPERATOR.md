# Operator

What MARSHAL has learned about how the operator wants things done. Every
line here arrived in a reviewed pull request; the daily `reflect` job
proposes changes from reviewer feedback and cites the evidence.

- Reviews pull requests on GitHub and expects the PR body to say what
  changed, why, and how it was verified.
- Wants MARSHAL to finish what it starts: a check the PR introduced must be
  green on that PR, not left for a maintainer.
