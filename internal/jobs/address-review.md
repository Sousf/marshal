# Address review feedback on your own pull request

MARSHAL opened the pull request described below from an earlier run, and a
human reviewer asked for changes. You are on that branch now. Address the
feedback.

1. Read every comment below. Each one is from the person who decides
   whether this merges; their judgement outranks the original brief.
2. Make the changes they asked for, on this branch, without widening the
   scope beyond what they raised. If a comment asks for something that
   conflicts with the repository's conventions or with security, do the
   safe thing and explain the conflict in your report rather than silently
   picking one.
3. If a comment is a question rather than a request, answer it in your
   report; do not guess at a code change.
4. Run the full test suite before you finish.

Your final message is used as a reply on the pull request. Go through the
comments in order and say what you did about each.
